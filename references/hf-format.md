# HF 中英文与数据格式

仅在材料包含中英文混排、技术词、数字、日期、时间、金额或单位时读取本文件。先应用 `hf-core.md`。

## 中英文混排、大小写与技术词

| 规则 ID | 触发条件与判定 | 直接修改示例 | 例外 |
|---|---|---|---|
| HF-MIX-01 | 中文正文或说明中的独立英文词、缩写、数字未采用产品定义的间距规则，且同页写法不一。 | `支持OAuth登录` → `支持 OAuth 登录` | 紧凑控件可采用无空格规则，但同类控件必须一致。 |
| HF-MIX-02 | 同一概念无规则切换中文全称、英文全称和缩写。 | `LLM`、`大模型`、`Large Language Model` → 选定主名称。 | 技术文档、代码字段和不同受众内容可有层级差异，须在术语表声明。 |
| HF-MIX-03 | 正式品牌、产品名或技术协议的大小写被任意改写。 | `Github` → `GitHub`；`Oauth` → `OAuth` | 用户输入值、外部系统返回值、代码和历史数据不强制改写。 |
| HF-MIX-04 | 中文+英文混合概念的连接方式不一致。 | `batch数`、`Batch 数`、`批处理数` → 选定主名称。 | 确认技术含义前只写“建议统一/待确认”。 |
| HF-MIX-05 | 中文语境出现未定义的英文操作词，增加理解成本。 | `点击 save` → `点击“保存”` | 面向开发者、命令行、代码字段或官方英文产品名。 |
| HF-MIX-06 | 以 `&`、`+`、`@` 代替中文连接词，且不是正式名称或技术语法。 | `导入&导出` → `导入和导出` 或 `导入/导出` | URL、邮箱、公式、标签、正式产品/功能名。 |
| HF-MIX-07 | 中文句中将英文复数、所有格或不必要冠词作为 UI 名称一部分。 | `查看 Users` → `查看用户` | 菜单、外部系统名称或不可翻译的字段值。 |
| HF-MIX-08 | 同一技术术语无规则使用全角/半角括号、短横线、大小写或空格。 | `API密钥`、`API 密钥` → 按术语表统一。 | 术语表优先。 |

## 数字、日期、时间、金额与单位

| 规则 ID | 触发条件与判定 | 直接修改示例 | 例外 |
|---|---|---|---|
| HF-NUM-01 | 同类数字无规则混用中文数字与阿拉伯数字。 | `共有三条`、`共 5 条` → `共 3 条`、`共 5 条` | 品牌文案、固定成语、法律/金融文件或语义必须使用中文数字的内容。 |
| HF-NUM-02 | 同类数据的小数位、千位分隔、正负号或单位精度不一致。 | `1,000`、`1000` → 统一一种。 | 数据源原样展示且明确标注来源。 |
| HF-NUM-03 | 百分号、货币符号、温度等紧随单位的符号与数字间无规则加空格。 | `60 %` → `60%`；`¥ 99` → `¥99` | 产品规范另有规定时优先。 |
| HF-NUM-04 | 独立拉丁单位的空格规则不一致。 | `10MB`、`10 MB` → 选定一种。 | 技术协议、字段值、代码和设备厂商原始单位。 |
| HF-NUM-05 | 范围表达混用 `-`、`~`、`至`，或遗漏两端单位。 | `1-10GB` → `1–10 GB` 或 `1 至 10 GB` | 日期/版本号遵循各自格式规则。 |
| HF-NUM-06 | 同一信息层级无规则混用绝对日期、相对日期和不同日期格式。 | `2026/8/1`、`2026-08-01` → 统一。 | 消息时间线可用相对时间，但须与列表、详情场景区分。 |
| HF-NUM-07 | 时间缺少时区、24/12 小时制或零填充规则，且同一产品出现多种格式。 | `9:5`、`09:05` → `09:05` | 用户本地化设置、外部数据源或法律凭证要求不同格式时需明确来源。 |
| HF-NUM-08 | 输入提示、校验错误与实际可接受格式不一致。 | 占位符 `YYYY-MM-DD`，错误提示却要求 `2026/01/01` → 统一格式。 | 无。 |
| HF-NUM-09 | 数值、单位和上限/下限构成歧义。 | `最大上传 10 文件` → `最多上传 10 个文件` | 无。 |
| HF-NUM-10 | 同一界面或流程的数字分组符、小数符、日期顺序或负数写法不一致；locale 未确认时使用有歧义格式。 | `1,234.5` 与 `1.234,5` 混用；`03/04/2026` 含义未确认时先标待确认，再按确认后的日期改用无歧义格式。 | 按用户设置、项目 locale、技术协议或来源格式展示时遵循已确认约定；不得仅凭单个样例推断全产品格式，也不得自行解释歧义日期。 |
| HF-NUM-11 | 多币种场景只显示可能歧义的货币符号，或金额与币种的对应关系不清。 | 多币种报表中的 `$100` → 在语境允许时明确使用 ISO 币种代码，并按目标 locale 选择其位置。 | 单一币种且界面已明确标注时，重复显示币种代码可能冗余；不要擅自补币种、税费或金额精度。 |
| HF-NUM-12 | 百分比的数值尺度、格式提示或校验范围不清/不一致，或同一内容重复表达百分比单位。 | `0–1` 与 `0–100%` 同时出现但未说明尺度 → 按实际输入/显示约定明确一种；`20% 百分比` → 删除重复单位。 | 不得自行把小数换算为百分数，或假定数值代表比例、增长率、百分点。 |
| HF-NUM-13 | 同一数据字段的显示精度、小数位或四舍五入表现不一致，且可能影响用户比较或决策。 | 同列 `1.2`、`1.20` 混用 → 核对产品精度规则并统一显示。 | 尾随零可能表达测量精度；仅凭不同小数位不能断定数据错误，未经授权不得改值或舍入。 |
| HF-NUM-14 | 数值缺少理解所必需的单位，或区间只给一端单位而导致量纲不明。 | `范围 5–10` → 仅在上下文未明确时补全为 `5–10 GB`。 | 若列标题、字段标签或分组标题已清楚标明单位，不必重复；单位制与换算须遵循已确认的产品/地区规则。 |
| HF-NUM-15 | 将编号、代码、邮编、电话或其他标识符按普通数值本地化、分组、舍入，或丢失前导零。 | `订单号 001234` 不应被改成 `1,234`。 | 对真实数值字段的显示格式按 locale 和产品规则处理；无法判断字段是数值还是标识符时标记待确认。 |
