# PaletX 数据格式规则附录

仅在用户/项目明确采用 PaletX，且审查材料涉及进度、数值、单位、表格数据、空数据、脱敏或时间单位时加载。通用数据格式规则另读 `hf-format.md`；目标 locale 明确为 en-US 时另读 `en-us-localization-rules.md`。不要把截图未定义的技术含义推断成规则。

`PX-DAT-04` 至 `PX-DAT-13` 根据 PaletX 数据格式指南页面截图中可辨认的内容提炼。来源登记为 `SRC-PX-DATA-001`；在线页面当前版本尚未核验。单位词表仅择要保留，不在此穷举。

| 规则 ID | 可判定要求 | 审查示例 | 例外/说明 |
|---|---|---|---|
| PX-DAT-04 | 进度可用分子/分母形式呈现；使用时须确保用户能识别其表示当前进度而非比率或两项独立数值。 | `12/20` 表示 20 项中的 12 项。 | 百分比更适合比较完成比例时可按产品设计选用；不可改变真实总数或完成数。 |
| PX-DAT-05 | 数据小数位通常保持两位有效精度；千位默认用分隔符便于阅读；极大或极小数值在空间/计算场景可用科学记数法。 | `123.45`、`123,456,789`、`6,100,000,000 → 6.1×10^9`。 | 源页未明确“两位有效精度”是否严格等于两位小数；特殊场景、计量精度、locale 或工程字段按已确认规则处理，不舍入或改值。 |
| PX-DAT-06 | 百分比按比例含义显示为整数或保留两位小数，并在同一数据集内统一。 | `90%`、`99.99%`。 | 不得为符合样式而转换比例、百分数或百分点；业务精度要求优先。 |
| PX-DAT-07 | 通用计量单位默认小写；标准符号、专有单位及通信/存储单位按其标准大小写，不可把大小写不同的单位视为同义写法。 | `m`、`km`；注意 `bit`/`Byte`、`Kb`/`KB`、`Mb`/`MB`、`bps`/`Bps`、`dBm`/`dB`、`μs`/`ms`、`°C`、`Hz`、`W`、`Ah`。 | 页面另列 VMAX 专业单位词表；技术领域和项目批准的单位名优先。此处择录易混写法，不穷举或擅自改释专业单位。 |
| PX-DAT-08 | 表格采用统一对齐；默认左对齐。对数值大小有比较意义的列，在简单表格等适用场景可右对齐。 | 普通文本列左对齐；速率、容量或比例比较列可按表格设计右对齐。 | 依赖小数点对齐、混合内容、排序或可读性的专用表格可采用已定义的例外。 |
| PX-DAT-09 | 表格中与数值直接对应的单位/百分比与数据一起呈现；唯一单位可放表头，多种单位则在单元格明确标出。数量单位置于数值后，二者间留空格；货币单位通常置于数值前。 | `103 Kbps`；同列仅一种单位时在列头标注。 | 货币与计量单位遵循目标 locale、法定/行业及项目惯例；表头已充分说明时不重复单位。 |
| PX-DAT-10 | 存储、容量等数据优先选择便于阅读的合适量级；同一表/流程统一量级策略。 | 源页示例：大于 `1M` 的值可用 `M` 表示，大于 `1G` 的值可用 `G` 表示。 | 截图未定义 `M/G` 对应的具体单位、进位基数或舍入方式；不得据此推断 MB/GB、十进制/二进制或改动精度，须按产品领域规则确认。 |
| PX-DAT-11 | 分开展示空数据、读取失败/不适用与数值零，避免用空白、`--`、`N/A` 或 `0` 混淆数据状态。 | 空采集值显示为空；无法读取或不涉及的属性按产品约定显示 `--`/`N/A`；真实数值零显示 `0`。 | `--` 与 `N/A` 的含义和强调程度须由产品统一定义；数据异常不能伪装成空值，零值不得隐藏。 |
| PX-DAT-12 | 涉及用户隐私或敏感信息时，按已批准的数据分类采用全部或部分脱敏；显示掩码不能被描述成加密。 | 密码/高度敏感信息全遮蔽；经批准的 IMSI、证件号、账户、姓名或地址示例只保留必要片段。 | 脱敏范围由安全/隐私规范确定；截图中的示例不是授权披露字段的依据。仅当底层确实执行密码学加密时才称“加密”。 |
| PX-DAT-13 | 编辑页时间单位使用小写并统一复数；查看页数字后留空格、单位小写。可实现时按数量区分单复数；缩写不加 `s/es`。 | `1 day`、`2 days`；`1 s`、`1 min`。 | 截图对无法区分单复数的回退示例含 `1 days`；此写法与自然 en-US 语法有冲突。en-US 项目应优先使用正确单复数或提交项目确认，不机械照搬该例。 |

## 组合使用与报告

按任务读取本附录中的相关规则，不必机械加载全部 PX 数据项。先保留数据本义，再检查呈现一致性；不做未经授权的数值换算、舍入、技术单位释义或隐私披露判断。报告引用实际影响结论的 `PX-DAT-*` 编号，并区分已确认问题与待确认的产品定义。
