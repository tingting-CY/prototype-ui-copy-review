# HF 语法、语气与可读性

仅在材料包含病句、歧义、冗余、人称、语气、简繁混用或实现术语时读取本文件。先应用 `hf-core.md`。

| 规则 ID | 触发条件与判定 | 直接修改示例 | 例外 |
|---|---|---|---|
| HF-LNG-01 | 句子缺少谓语、宾语或必要连接，无法判断发生什么。 | `开启后后台日志中将完整的请求数据` → `开启后，后台日志将完整记录请求数据。` | 标题、标签、按钮和状态标签不要求完整句。 |
| HF-LNG-02 | 否定词、范围词和条件词位置产生歧义。 | `不支持所有成员删除` → 按真实权限改为明确表达。 | 无；必须按真实权限重写。 |
| HF-LNG-03 | 并列项不平行，或修饰关系不清。 | `创建、编辑和删除项目权限` → `创建项目、编辑项目和删除项目的权限` | 空间受限时可通过表头、图标或层级表达省略。 |
| HF-LNG-04 | 无规则混用“您/你”、第一人称、无主语命令式和过度拟人化语气。 | 按品牌规范统一。 | 客服/社交产品可用特定人格语气，但须全局一致。 |
| HF-LNG-05 | 使用责备、模糊或无法行动的表达。 | `您输入错误` → `请输入有效的邮箱地址` | 安全告警可强提醒，但不得攻击用户。 |
| HF-LNG-06 | 无意义冗余词降低扫描效率。 | `请您点击按钮进行保存操作` → `保存` 或 `点击“保存”` | 教学引导可保留必要步骤描述。 |
| HF-LNG-07 | 同一 zh-CN 产品无规则混用简繁体、异体字或地区用词。 | `设置`、`設定` → `设置` | 多地区产品按 locale 切换。 |
| HF-LNG-08 | 使用内部缩写、实现术语或未解释错误码作为普通用户的唯一说明。 | `RPC 调用失败` → `连接服务失败，请稍后重试` | 开发者工具、管理员诊断页或已定义技术术语。 |
