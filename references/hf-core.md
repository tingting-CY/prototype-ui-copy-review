# HF 通用判定基线

将本文件用于所有中文 UI 文案审查。它只定义判定边界；再按 `SKILL.md` 的路由读取与材料相符的规则分片。项目规范、法务文本、无障碍规范或已批准术语表优先于 HF 规则。

| 结果 | 使用条件 | 引用方式 |
|---|---|---|
| 违反规则 | 原文满足触发条件且没有适用例外。 | 引用对应 `HF-` 编号。 |
| 建议统一 | 材料内部存在不同写法，但没有足以决定唯一标准的产品规范。 | `建议统一：HF-…` |
| 待确认 | 改写会影响业务、品牌、法务、安全或技术定义。 | `待确认：HF-…` |

| 规则 ID | 判定规则 | 例外 | 审查动作 |
|---|---|---|---|
| HF-GEN-01 | 只报告可见、可读或由结构化材料明确提供的文字。 | 无。 | 模糊、截断、动态或未覆盖内容写为“未核实”，不得猜测。 |
| HF-GEN-02 | 一条问题只解决一个根因；同一根因影响多处时合并。 | 不同位置存在不同用户风险时可拆分。 | 列出全部受影响位置与唯一推荐写法。 |
| HF-GEN-03 | 修改不得改变权限、价格、时间、数据范围、可逆性、合规义务或系统真实状态。 | 经用户明确授权改写业务口径。 | 无法保持语义时标记“待确认”。 |
| HF-GEN-04 | 按组件语境判断，不能用同一标点或句式规则处理按钮、标题、字段和说明句。 | 无。 | 保留或说明组件类型。 |
| HF-GEN-05 | 未提供产品规范时，不把偏好写成硬性错误。 | 明显错别字、语义矛盾、缺失谓语等基础错误除外。 | 降为 P3 或“建议统一”。 |
