# HF 标点、符号与空格

仅在材料包含自然语言标点、混合符号、空格或省略号问题时读取本文件。先应用 `hf-core.md`。

## 句末标点与句子边界

| 规则 ID | 触发条件与判定 | 直接修改示例 | 例外 |
|---|---|---|---|
| HF-PUN-01 | 按钮、页签、菜单、导航、字段标签、状态标签使用完整句句号。 | `保存。` → `保存`；`待处理。` → `待处理` | 完整的多句说明、Toast、错误消息、空状态正文可使用句末标点。 |
| HF-PUN-02 | 完整陈述句、风险提示、错误说明或确认正文缺少必要句末标点，导致句子边界不清。 | `保存后配置立即生效请确认` → `保存后，配置将立即生效。请确认。` | 空间极窄且规范明确要求省略标点的单句提示。 |
| HF-PUN-03 | 中文自然语言句中无规则使用英文半角 `, . : ; ! ?`。 | `保存失败,请重试.` → `保存失败，请重试。` | URL、邮箱、代码、命令、正则、版本号和正式英文内容。 |
| HF-PUN-04 | 英文自然语言句中混入中文全角标点，且产品未规定双语排版例外。 | `Save failed，请 retry.` → `Save failed. Please retry.` 或完整中文化。 | 正式产品名、字段值或不可翻译的英文片段按主语言处理。 |
| HF-PUN-05 | 中文完整句以三个半角句点 `...` 表示省略。 | `正在加载...` → `正在加载……` | 代码、文件扩展名、路径、版本号、英文原文或已定义的加载动画字符。 |
| HF-PUN-06 | 中文句中引号、括号形态与主语言不一致。 | `请选择 "高级模式"` → `请选择“高级模式”` | 引用代码、键名、命令、原始数据或正式英文短语时保留半角引号。 |
| HF-PUN-07 | 字段标签已通过布局与输入框关联，仍无规则追加冒号，造成同页标签形态混杂。 | `名称：` → `名称` | 表格行、键值对摘要、正文内引出说明时可使用冒号；同类组件必须统一。 |
| HF-PUN-08 | 同一对象的并列项随意混用顿号、逗号、斜杠、`&` 与“和”。 | `导入、导出/同步` → 按真实关系改为 `导入、导出和同步` 或 `导入/导出` | 成对动作、技术路径、正式产品名可保留。 |
| HF-PUN-09 | 中文 UI 词组中斜杠两侧出现无意义空格，或同页混用 `A/B` 与 `A / B`。 | `导入 / 导出` → `导入/导出` | 数学式、路径表达、规范明确要求的分隔式排版。 |
| HF-PUN-10 | 范围、日期或版本无规则混用连字符 `-`、短横线 `–`、波浪线 `~` 与“至”。 | `1~10 条` → `1–10 条` 或 `1 至 10 条` | 产品规范优先；未提供时同类数据选择一种写法。 |

## 空格与不可见字符

| 规则 ID | 触发条件与判定 | 直接修改示例 | 例外 |
|---|---|---|---|
| HF-SPC-01 | 中文句中存在连续空格、行首行尾空格或标点前空格。 | `保存失败 ， 请重试` → `保存失败，请重试` | 代码块、等宽数据、刻意对齐的纯文本表格。 |
| HF-SPC-02 | 同一类中英文混排文案的空格策略不一致。 | `创建API 密钥`、`创建 API密钥` → `创建 API 密钥` | 设计系统明确规定紧凑控件不加空格时，整类控件统一。 |
| HF-SPC-03 | 数字与中文量词、百分号、货币符号之间无规则插入空格。 | `60 %`、`¥ 99` → `60%`、`¥99` | 数值与独立拉丁单位可保留一个半角空格，但全产品必须一致。 |
| HF-SPC-04 | 用不可见换行、制表符或多个空格做视觉对齐。 | `用户名[多个空格]状态` → 使用布局组件。 | 无。 |
